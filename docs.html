Users / Get a user

GET

/users/{id}

Retrieve a single user by their unique identifier.

Returns the complete profile for an active user. The response includes account details and timestamps, but never exposes the user's password or private authentication tokens.

Path parameters

Parameters required to identify the user.

NameTypeRequiredDescription
idstringYesThe unique ID of the user to retrieve.

Responses

The endpoint returns one of the following responses.

  • 200
    OK

    The user was found and returned successfully.

  • 404
    Not Found

    No user exists with the supplied ID.

  • 500
    Internal Server Error

    The request could not be completed due to an unexpected error.
